###### Вариант А: Штатные средства терминала (Ctrl+Z)

# Свернуть в фон: 
Нажмите на клавиатуре 
## Ctrl + Z.
Интерфейс исчезнет, процесс приостановится.
Продолжить работу в фоне: Введите команду:
```bash
bg
```

Теперь агент работает в фоне, а терминал свободен.
Развернуть обратно: Введите команду:
```bash
bg
```

Интерфейс rich мгновенно восстановится.

###### Вариант В: Просмотр статистики без разворачивания (Наша новая фича)
Если процесс работает в фоне (через --daemon, bg или tmux), и вы просто хотите быстро глянуть, сколько событий найдено, не переключая окна:
```bash
source venv/bin/activate
python main.py --status
```

Эта команда за 1 секунду считает файлы processed_posts.json и events_output.json и выведет красивую сводную таблицу прямо в текущий терминал, не мешая фоновой работе.
